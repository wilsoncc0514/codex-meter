改动为展示层调整（B 级）；无新网络调用、数据格式、定时器或兑换权限。保留旧应用包作为回滚路径。
主面板两张卡的合成数据渲染已检查，无需点击即可看到日期。测试套件、release 编译和签名检查通过。
本次交付另存于 `build/0.4.2/Codex 额度.app`，没有覆盖正在运行的 `build/Codex 额度.app`（0.4.1）。
未再次查询受限的真实明细接口；实际日期仍取决于服务端是否返回。未做真实鼠标滚动、跨平台和公证验证。
以下为首次接入数据接口时的验证记录。

基准：`2b4b09f`；分支：`codex/reset-credit-display`。

## 范围与规范

新增只读可用次数、逐张到期时间（系统时区），不添加兑换按钮或兑换请求。
复用 `account/rateLimits/read` 的 `rateLimitResetCredits`，不增加直连 HTTP、凭据读取、依赖或定时器。
接口依据：[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)，并核对本机 CLI 生成的 TypeScript 协议。

## 数据与安全

`availableCount` 是权威次数，不从卡片数组推算；未知与零严格区分。
只保留卡片日期，不保留 ID、账户信息或服务端自由文本。最多处理 100 条明细。
缺失/异常明细明确提示，不影响普通额度读取。到期时间不明时不假定永不过期。
数据仅保存在本次内存快照，不改变持久化格式；日志/缓存回退不会沿用重置卡数。
主要风险为显示不完整或过时的数据，而非消耗账户权益。网络认证及超时继续由现有 App Server 客户端负责。
