## 下载与安装

附件为 macOS 14+ Apple Silicon（M 系列）版本，附 SHA-256 校验文件。
解压后将 `Codex 额度.app` 放入应用程序目录。它是菜单栏应用：启动后点击顶部额度数字查看，不会弹出普通主窗口。

**签名限制：采用本地临时签名，未做 Developer ID 签名及 Apple 公证。** macOS 可能阻止直接打开；请仅在核实下载来源后按系统安全设置处理。未提供 Intel 二进制。
